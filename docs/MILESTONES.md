# Milestones & Rubric

| Week | Milestone | Submission | Status |
|------|-----------|------------|--------|
| 2 | Team formation & allotment | Team roster + 3 preferences | [ ] |
| 4 | Proposal: problem, dataset verified downloadable, related work (5 papers), work split | 2-page proposal (graded, 10) | [ ] |
| 6 | Data ready: cleaned, split, explored; baseline running | EDA notebook + baseline metrics (graded, 10) | [ ] |
| 8 | Mid-term review: first full model vs baseline | 10-min demo + slide deck (graded, 20) | [ ] |
| 10 | Improved models: ablations, >=2 architectures compared | Experiment log + results table | [ ] |
| 12 | Deployment: working end-to-end demo | Live demo link | [ ] |
| 13 | Final report (IEEE, 8-10 pages) + repo | Report + repo (graded, 15) | [ ] |
| 14 | Final presentation + viva; peer evaluation | 20-min demo + viva (graded) | [ ] |

## Rubric (100)
| Component | Marks | When |
|-----------|-------|------|
| Proposal quality & feasibility | 10 | Wk 4 |
| Data pipeline & baseline | 10 | Wk 6 |
| Mid-term review: model + results | 20 | Wk 8 |
| Technical depth: ablations, architecture comparison, evaluation rigour | 20 | Wk 10-13 |
| Working deployment / demo | 15 | Wk 12-14 |
| Final report & code quality (repo hygiene, reproducibility) | 15 | Wk 13 |
| Individual contribution (commits + viva + peer eval) | 10 | Wk 14 |

Marks are shared by the team except the individual component; a member with no verifiable contribution gets at most 40% of the team score.
